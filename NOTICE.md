# NOTICE — Data Provenance & Attribution

This project uses **three** datasets. All are clearly separated so no reader confuses
modeled results with real ones.

| # | Dataset | Nature | Used for |
| --- | --- | --- | --- |
| 1 | UCI Default of Credit Card Clients | Real, CC BY 4.0 | Credit-card default risk |
| 2 | LendingClub public loan files | Real, public | Loan profitability & pricing |
| 3 | "Halo Card" synthetic portfolio | Generated | Method: unit economics, offers |

---

## 1. Real data — UCI "Default of Credit Card Clients" ⭐

**Used by:** `scripts/fetch_real_data.py` → `sql/schema_real.sql` → `sql/real_analysis.sql`
→ `docs/real-data-findings.md`

**Citation (required by the license):**

> Yeh, I. (2009). *Default of Credit Card Clients* [Dataset]. UCI Machine Learning
> Repository. https://doi.org/10.24432/C55S3H

| Field | Value |
| --- | --- |
| Source | UCI Machine Learning Repository, dataset #350 |
| URL | https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients |
| License | **CC BY 4.0** — free to share and adapt with attribution |
| Content | 30,000 real credit-card clients (Taiwan, Apr–Sep 2005), 23 features |
| Outcome | `default payment next month` — **real observed defaults** |
| Default rate | 22.12% (matches the published ~22.1% baseline exactly) |

**What the real data adds:** genuine default outcomes, real behavioral correlations, and
real data-quality problems (undocumented category codes, negative bill amounts, an
imbalanced outcome). What it lacks: revenue, channel, fee, and offer fields — those are
modeled with stated assumptions (`scripts/fetch_real_data.py::ASSUMPTIONS`).

**Ethics note:** the dataset contains `SEX`, `EDUCATION`, `MARRIAGE`, and `AGE`. These are
carried **for fairness auditing only** (`sql/real_analysis.sql` Q7/Q8) and are never used
as targeting inputs or model features. That separation is deliberate and is called out in
the findings.

## 2. Real data — LendingClub public loan files ⭐

**Used by:** `scripts/fetch_loan_data.py` → `sql/schema_loans.sql` → `sql/loan_analysis.sql`
→ `docs/loan-findings.md`

| Field | Value |
| --- | --- |
| Source | LendingClub public loan statistics files |
| URL | https://www.lendingclub.com/info/download-data.action |
| License | Publicly published by LendingClub for research/analysis use |
| Content | 115,675 loans (2019Q1 vintage), 144 raw columns, 102,581 resolved |
| Contains | **Real interest collected, charged-off principal, and recoveries** |

**What this adds:** the UCI data has outcomes but no revenue. LendingClub's cash-flow fields
make profit-and-loss, pricing-by-risk-grade, and risk-adjusted return analysis possible —
including the finding that risk-based pricing held at 36-month terms and broke down at 60.

**Data notes:** LendingClub blanks borrower identifiers (`id`, `member_id`) in public files, so
`loan_id` here is a generated surrogate key used only as an identifier. Two junk rows precede
the real header and footer totals follow the data; the ingest handles both.

**No PII:** the published files contain no names, addresses, or contact details. State is the
finest geographic granularity and is used only as a monitoring view, never as a targeting input.

## 3. Synthetic data — "Halo Card" portfolio

**Used by:** `scripts/generate_synthetic_data.py` → `sql/schema.sql` → `sql/*.sql`
→ `output/executive-memo.md`, `output/dashboard.html`

Fictional portfolio generated by a seeded script. No real customer data. Correlations are
**designed**, not discovered — so synthetic results demonstrate method and reasoning, while
the real datasets demonstrate findings.

## How to tell them apart in this repo

| Path | Dataset |
| --- | --- |
| `sql/schema.sql`, `sql/kpi_dashboard.sql`, `sql/segmentation.sql`, `sql/pricing_sensitivity.sql` | Synthetic |
| `sql/schema_real.sql`, `sql/real_analysis.sql` | **Real (UCI)** |
| `sql/schema_loans.sql`, `sql/loan_analysis.sql` | **Real (LendingClub)** |
| `output/executive-memo.md`, `output/dashboard.html` | Synthetic |
| `output/real/` | **Real (UCI)** |
| `output/loans/` | **Real (LendingClub)** |
| `docs/analysis-log.md` | Synthetic build log |
| `docs/real-data-findings.md` | **Real-data findings (UCI)** |
| `docs/loan-findings.md` | **Real-data findings (LendingClub)** |

## Reproducing

```bash
pip install duckdb xlrd

# UCI credit-card data (downloads ~5MB)
python3 scripts/fetch_real_data.py
python3 scripts/run_real_analysis.py

# LendingClub loan data (downloads ~20MB)
python3 scripts/fetch_loan_data.py
python3 scripts/run_loan_analysis.py

# Synthetic portfolio (no external data)
./scripts/run_all.sh
```

Raw datasets are cached in `.cache/` and are **not** committed to this repo — they are
downloaded on demand rather than redistributed, keeping license obligations simple
(attribution is given here and in the generated reports).
